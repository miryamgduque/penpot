The shift

Design guidance used to live in the AI's head — or a doc it was free to ignore.

We moved it into the design itself: your rules live in Penpot, at the app, team, and file level. Every agent that touches the work inherits them the same way — and the strict ones are guardrails the work physically has to pass, not hints in a prompt.

Why it matters

Five things that change.

bidirectional

The design talks back

Not a one-way prompt. The agent reads your live file and tokens; the file flags rule violations back — to the agent and to you — as you work, and batches them into one fix.

embedded

No external app to reach the tools

The chat agent is a panel next to your canvas. You don't open Claude Code or Cursor to use the design tools — they're already here, where you're designing.

no‑sync

Nothing to keep in sync

Skills live in Penpot — in the file and in the team database, seeded from the official penpot-ai-kit. No rule files to copy into each person's setup, no drift between them.

layered

Rules at every level

Manage skills & rules for the whole instance, one team, or a single file. They cascade — most-specific wins — and anything marked mandatory can't be loosened below.

enforced

Guardrails, not suggestions

“Use only our color tokens” isn't advice. The write path rejects an off-token fill or stroke — no matter which AI model, in-app or external, tried to make it.

skill vs rule

Two kinds, on purpose

A skill is know-how the agent follows (playbooks, conventions). A rule is a constraint that can be watched and enforced. Same system, different teeth.

What's in the branch

Four moving parts, one idea.

The work spans Penpot's backend, its dashboard, the design canvas, and the external door — knit together so a rule authored once behaves identically everywhere.

The shared brain
One engine parses the skill format, layers the App → Team → File cascade, and runs the enforcement guard. Both the in-app agent and the external door use it, so they can never drift apart.
The control room
A database table plus a native Skills & Rules page inside Penpot's dashboard — seeded with 16 starter skills from penpot-ai-kit. Create, edit, and switch rules on or off at the app and team level.
The workspace
Two docked panels next to the canvas: an Agent you chat with, and a Skills manager with a live Audit that watches the file for rule violations and hands them to the agent to fix in one pass.
The open door
External agents — Claude Code, Cursor, a CI job — can still connect over MCP and inherit the exact same rules and the exact same enforcement. Optional, not required.

In plain terms

Think of a style guide the AI physically cannot ignore — like a spell-checker that won't let the typo through.

Every team has design rules: the right colors, the right spacing, sensible names. Normally you just hope everyone — and every AI — remembers them. This bakes the rules into Penpot itself. The AI designer reads them automatically, and for the strict ones it simply can't produce work that breaks them.

The rules are set once and shared by the whole team, they live with your files, and you talk to the AI right inside Penpot — no second app to open, nothing to keep in sync. Set the guardrails; let anyone (or any AI) design fast without going off-brand.
